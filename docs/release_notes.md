# CAIT 0.2.0: evidence-derived capability accounting and conditional reproduction bounds

Adds an opt-in source-bound finite accounting kernel while preserving the legacy language-neutral
schemas, fixtures, imports and `cait-validate`. Exact rational replay derives stock, service outcomes,
disjoint origin shares, unique physical costs, receiver-qualified reuse, lifecycle and corrected
window balances. An independent checker reconstructs source histories and mathematical witnesses.

Conditional nonnegative next-generation models support exact lower/upper spectral witnesses, scoped
principal blocks and complete finite families. Expected, pathwise, statistical and causal conclusions
remain distinct. Unknown evidence, truncated sources, failed checks and resource debt stay explicit.

The additive `cait-analyze` CLI packages 11 inert histories and actual released VEK 1.3.0 / CCR 1.8.0
JSON fixtures. CCR exports are task proposals and derived sidecars; no execution or arrival verdict
is granted. No companion repository was modified.

The tag workflow builds once, checks the distributions and installs the same wheel on three OSs,
publishes via the configured Trusted Publisher, then attaches identical artifacts and SHA256SUMS.
Post-publication public-index checks are recorded here after they actually pass.

No external empirical collective-intelligence acceleration experiment was performed. CAIT computes
declared finite accounting and checks scoped mathematical/evidence objects. It does not establish
causal endogenous reproduction, AGI/ASI, infinite growth, or execution authority.
