# CAIT 0.2.0

CAIT preserves the language-neutral 0.1.0 schema/validator surface and adds an opt-in
finite computation profile. It derives balances from source-bound events and checks
conditional reproduction witnesses. The new kernel is experimental and model-conditional.

The working path is source bundle → local validation → dependency/ledger replay →
window balances → receiver reuse and disjoint accounting-origin shares → conditional
matrix bounds → independent report check → CCR proposal/sidecar → offline installed examples.

No external empirical collective-intelligence acceleration experiment was performed.
CAIT computes declared finite accounting and checks scoped mathematical/evidence objects.
It does not establish causal endogenous reproduction, AGI/ASI, infinite growth, or execution authority.

Read [accounting semantics](accounting.md), [mathematical premises](reproduction.md),
[interchange limits](interchange.md) and [commands](cli.md). Generated references describe
the additive `schemas/accounting` namespace; all historical schemas and fixtures remain intact.
